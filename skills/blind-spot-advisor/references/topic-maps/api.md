# Starter topics: public API or developer platform

Add to `common.md`.

## Contract
- **Versioning**: how breaking changes are introduced, how long old versions live.
- **Deprecation policy** and how users are warned.
- **Error format** and error codes, stable over time.
- **Pagination, filtering, idempotency** for writes.
- **Webhooks**: retries, signatures, ordering.

## Access
- **Authentication**: keys, OAuth, scopes.
- **Key rotation and leaked keys**.
- **Rate limits and quotas**, and what the client sees when it hits them.
- **Abuse and scraping**.

## Developers
- **Documentation**: reference, quick start, examples, changelog.
- **SDKs**: which languages, who maintains them.
- **Sandbox or test mode**.
- **Support channel** and response times.

## Business
- **Pricing per call or per plan**, and overage.
- **Terms of use for the API**, including what may be built with it.
- **Usage analytics** per customer.
